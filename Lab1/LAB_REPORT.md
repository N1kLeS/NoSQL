# Отчёт

## Version 0.3

### Что сделал:

- Пользователь хранится в bucket `users`: key — `userId`, value — JSON с полями `id`, `name`, `email`.
- `userId` выбран ключом, потому что пользователь запрашивается по идентификатору без поиска по всем записям.
- Приложение сохраняет и читает данные через HTTP API Riak KV. Этот способ поддерживается используемой версией Riak и не требует устаревшего Java-клиента.
- Для отсутствующего пользователя возвращается `HTTP 404`, для некорректных данных — `HTTP 400` с сообщением на русском языке.
- Пользователь расширен настройками `emailNotifications`, `pushNotifications` и `orderStatusNotifications`. Настройки сохраняются внутри JSON пользователя в bucket `users`.
- Структуру Riak изменять не потребовалось: значение записи представляет собой JSON и не имеет фиксированной SQL-схемы.
- Старые записи без настроек продолжают читаться; для них все виды уведомлений по умолчанию отключены.
